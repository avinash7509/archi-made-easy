# Roadmap

The direction: evidence-backed architecture reviews that produce diagrams people can use and decisions people can challenge.

## Available in v0.1

- [x] Versioned semantic model and native editable diagram exports
- [x] Contextual six-pillar checks with explicit unknowns
- [x] Structural blast radius and bounded scenario calculations
- [x] Preserved as-is, proposed target, and semantic diff
- [x] Standalone interactive workbench and local execution
- [x] Thirty deterministic fixture cases

## Next: make the first review excellent

- [ ] More source-grounded provider rules and valid counterexamples
- [ ] Better laptop/print layouts and stronger label/crossing checks
- [ ] Curated view aggregation for complex C4 and hybrid systems
- [ ] Requirement-specific tradeoff and ADR generation
- [ ] Richer draw.io round-tripping and unsupported-change handling

## Deepen the architecture coverage

- [ ] Broader IaC interpretation and evidence tracing
- [ ] Service-specific recovery and failover-capacity modeling
- [ ] Complete secondary UML/ERD notation
- [ ] Deeper SAP, MuleSoft, Databricks and ServiceNow packs
- [ ] Expanded conditional provider catalogs

## Prove the results

- [ ] Thirty tasks × three models × three repetitions, with retained evidence
- [ ] Blind visual comparisons with matched tools and budgets
- [ ] Published false-positive, missed-defect and repair-success results

These are priorities, not promised dates. [Bring a real architecture problem](https://github.com/avinash7509/archi-made-easy/issues/new?template=architecture-trap.yml) to help prioritize the work. [Current limitations](docs/implementation-status.md).
