# Implementation status — 0.1.3

The v0.1.2 update adds a standard-library Python fallback for restricted hosts: interactive HTML, editable draw.io, SVG and CASG, with optional Pillow PNG. It does not run Node WAF/schema/availability engines or preserve full nested draw.io round-trip metadata. Node remains the primary engine. Both paths provide explicit artifact manifests; browser installation is unnecessary for HTML.

The v0.1.3 compact package includes the schema and MCP example inside references/, compact multi-column Python layouts, explicit view slicing with connector pages, and a readable inspector. It is tested without the Node runtime or third-party Python modules. Scope labels are not nested boundary geometry.

## Executable now

- CASG v1 schema, stable IDs, containment/edge/evidence validation, bounded repo path checks.
- Six-pillar contextual assessment with pass/fail/unknown/not-applicable findings and coverage.
- Provider-aware WAF association checks for a bounded service catalog, origin bypass checks, residency/recovery consistency, AI permissions and operational checks.
- Proposed control remediation, explicit supported WAF policy attachments and poison-message recovery queues; source preservation and semantic diff.
- Fixed-point blast radius for required/optional/fallback/quorum dependencies and containment outages; exact small-graph availability, seeded latency sampling and bounded queue scenarios.
- ELK nested graph layout, sequence layout, capability grid, attribute rows for generic ER/class views.
- Editable native draw.io with baseline metadata, compressed/uncompressed import, scoped page selection and conflict reports.
- SVG, PNG, PDF, standalone HTML with view selection, search, zoom, failure highlighting and side-by-side models.
- Architecture dossier, illustrative decision matrix/ADR, evidence reports, browser export checks and explicit visual review records.
- Official icon cache acquisition, pinned Google checklist references, a small source-conditioned provider-fact catalog, skill authoring references and installation tooling.
- Thirty deterministic fixture cases, core/browser tests, cross-platform CI configuration.

## Not complete against the full roadmap

- No universal cloud/enterprise configuration validator. Most checks inspect declared CASG controls; they do not prove deployed settings or parse all IaC expressions.
- No complete AST/call-graph extraction, PDF/image ingestion engine, or autonomous model-provider integration. The skill delegates source interpretation and design judgment to the host agent.
- No automatic safe replication/migration synthesis for arbitrary stateful systems. Redundancy and recovery-test failures remain visible instead of being erased by setting booleans.
- The provider catalog is intentionally small; comprehensive Azure conditional SLAs, pricing, regional latency measurements and account quota overrides are not bundled.
- Secondary UML/ERD views use generic graph/attribute rendering, not full formal notation. C4 abstraction is agent-authored view selection rather than inferred semantic aggregation.
- Geometry checks cover core overlaps/containment/obstructed routes. Complete mathematical edge-label/crossing assurance and automatic perceptual review are not established.
- Imported custom stencils/UserObject wrappers and concurrent multi-page editing are preserved/reported, not fully interpreted or merged.
- The six reference-inspired fixtures are smoke cases, not pixel-faithful reconstructions of the supplied diagrams.
- No 270-run multi-model evaluation, blind preference panel, executed macOS/Linux release verification, npm publication has occurred. The source is public on GitHub.

These are material implementation boundaries, not completed features. Fixture pass rates must not be used to claim the release quality targets or world-best performance.
