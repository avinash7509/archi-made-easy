## A clearer visual system for the compact workbench

The compact renderer now uses filled role headers, shaded cards and a role legend instead of nearly monochrome boxes:

- Teal: user experience
- Purple: intelligence and MCP protocol
- Blue: API integration
- Amber: identity and secrets
- Green: enterprise applications and data
- Cyan: operations

Protocol lines and arrowheads are stronger and color-matched. Numbered flow badges, a dark toolbar and a cleaner inspector improve scanning. Role colors also carry into SVG and editable draw.io; optional Pillow PNG uses matching card fills. Colors describe roles, not verified security status. Existing failure highlights still show red/amber conditions.

The five-view MCP example was visually inspected, and existing layout/interaction tests check text bounds, route geometry, model coverage and failure inspection. Release automation reruns all tests and extracted-package checks before uploading assets.

For restricted Python hosts, upload **archi-made-easy-0.1.4-compact.zip** directly. It contains SKILL.md plus agents/, references/ and scripts/. The full Node package is available separately. Existing compact-renderer limitations remain: no full WAF/availability engine, nested boundary geometry or PDF, and no universal hosted-agent compatibility guarantee.
