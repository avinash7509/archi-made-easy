## Unified master canvas for the compact renderer

The Python workbench now opens the complete model, including nested parent-defined boundary containers. Request/data, async, security and operations lenses dim unrelated elements without deleting nodes. Explicit relationship plane metadata is supported alongside kind-based defaults.

- Two-line role-colored cards; full controls and evidence in the inspector.
- Inline protocol badges, semantic connector strokes and clickable sequence steps.
- Cursor-centered wheel zoom, background drag, Fit, Reset, search centering and minimap.
- Browser-side dependency propagation: red source, amber impact, green surviving nodes and blue dashed fallback/quorum connections. Capacity and recovery timing remain assumptions.
- Top-level architecture-master.svg and a downloadable architecture-artifacts.zip. Master PNG uses installed CairoSVG, Resvg or Chromium; missing rasterizers are reported.
- CASG edges support optional protocol, port, auth, plane and controls metadata. Hierarchy uses existing boundary components and parent IDs.

Twenty local automated tests passed. The master fixture checks complete node/edge coverage, nested containment, text bounds, leaf-avoiding orthogonal routes, lens DOM preservation, reset, minimap and failure interaction. The preview was inspected and overlapping protocol badges corrected. These are fixture results, not a universal geometric guarantee.

This refactors the compact Python workbench. The full Node policy/availability engine remains separate. The Python renderer still does not run that assessment engine or certify deployed controls. Boundary containers show modeled containment, not proof of network isolation. Dense systems may need zooming and manual review.
