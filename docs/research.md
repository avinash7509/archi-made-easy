# Research baseline

Inspected repository entry points, architecture schema/routing guidance and evaluation protocols:

- diagram-design: https://github.com/cathrynlavery/diagram-design/tree/e57eda6102a19444538ebd611d39534fad65b663
- Archify: https://github.com/tt-a1i/archify/tree/a4065941f12be7967436261d9934784e381d423c

Lessons: preserve architecture meaning during repairs, separate machine checks from actual visual inspection, retain evidence and failures, and avoid treating small fixture runs as model reliability claims. diagram-design's editorial defaults need adaptation for dense enterprise diagrams; Archify's schema/render/check pipeline provides a useful comparison target.

No code was copied from either repository. Comparison trials have not been run.

Google checklist revision and content hashes are recorded in `catalogs/google-checklists.json`. Original checklist text is not redistributed. Vendor icon acquisition sources and archive checksums are recorded in the local cache manifests.
